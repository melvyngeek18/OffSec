📋 Instructions d'installation

  1. Téléchargez le fichier APK en cliquant sur le bouton ci-dessus
  2. Ouvrez les Paramètres de votre téléphone Android
  3. Allez dans Sécurité → Activez "Sources inconnues"
  4. Ouvrez le fichier APK téléchargé
  5. Cliquez sur Installer
  6. L'application sera disponible sur votre écran d'accueil
📦 Taille: ~50 MB
🤖 Android 6.0 ou supérieur
📍 Permissions: GPS, Internet
